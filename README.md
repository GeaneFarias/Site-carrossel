# 🌟 Site com Carrossel de Imagens

Este é um site simples com um carrossel de imagens responsivo, desenvolvido com HTML, CSS e JavaScript. Ideal para quem está começando a explorar interações visuais e componentes reutilizáveis no front-end.

---

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
